# PS5 Launcher

Лаунчер игр для Windows в стиле интерфейса PS5 — замена Steam Big Picture: полноэкранный режим, управление геймпадом, живые фоны и лента с новостями, трофеями и друзьями.

## Установка

Скачайте `PS5-Launcher-Setup-x.y.z.exe` из [Releases](https://github.com/SoFTeR1/ps5-launcher/releases/latest) и запустите.
Дальше лаунчер обновляется сам: **Настройки → Проверить обновления**.

## Управление

| Действие | Геймпад (Xbox / DualSense) | Клавиатура |
|---|---|---|
| Навигация | D-pad / левый стик | Стрелки |
| Выбрать / Играть | A / ✕ | Enter |
| Назад, скрыть заставку запуска | B / ○ | Esc / Backspace |
| Параметры игры | Y / △, Start | Q, клавиша меню, правый клик |
| Добавить игру | X / □ | N, Insert |
| Полный экран вкл/выкл | — | F11 |

**Кнопка Xbox (Guide) или View+Start** — вызвать лаунчер из любого места (даже из игры) и открыть Центр управления: музыка, друзья, возврат в игру. Повторное нажатие возвращает в игру. Работает с XInput-геймпадами (Xbox и совместимые); если Steam перехватывает кнопку Xbox, используйте View+Start.

Текст с геймпада вводится экранной клавиатурой: ✕/A — клавиша, □/X — стереть, △/Y — пробел, Start — готово.

Вниз от кнопки «Играть» — лента: новости, трофеи, «Продолжить», статистика, друзья, музыка, скидки Steam, состояние ПК.

## Возможности

- Разделы «Игры» и «Медиа»; exe, ярлыки `.lnk`/`.url`, ссылки `steam://…`
- Импорт установленных игр Steam с обложками, фонами и логотипами
- Анимация запуска поверх всех окон (в том числе Steam); лаунчер уходит в фон, когда игра запустилась, и возвращается, когда она закрылась
- Время в игре и статус «Запущено» — и для exe, и для игр Steam (время берётся из самого Steam)
- Свой фон для каждой игры и общий фон — картинка или видео (mp4/webm); живые фоны из трейлеров Steam
- Новости игр из Steam, трофеи (достижения), друзья онлайн — для трофеев и друзей нужен бесплатный [Steam Web API-ключ](https://steamcommunity.com/dev/apikey) (Настройки → Аккаунт Steam)
- Аккаунт лаунчера, друзья и чат (иконка друзей вверху): регистрация не нужна, друзей можно найти по нику, сообщения шифруются и доставляются через открытую сеть Nostr, даже если друг был не в сети; статус «В игре: …» виден друзьям
- Статистика: часы за неделю/месяц, любимая игра
- Скидки Steam (сначала — игры из вашего списка желаемого)
- Мини-плеер для Spotify, Яндекс Музыки и браузеров (через медиасессию Windows)
- Состояние ПК: CPU, RAM, GPU (NVIDIA), свободное место на дисках
- Раскладка подсказок PlayStation / Xbox / авто

Данные хранятся в `%APPDATA%\PS5 Launcher\library.json`.

## Разработка

```bash
npm install
node node_modules/electron/install.js
npm start
```

Если `node_modules\electron\dist\electron.exe` не появился (бывает на Node 26), распакуйте архив из `%LOCALAPPDATA%\electron\Cache` в `node_modules\electron\dist` и создайте `node_modules\electron\path.txt` с текстом `electron.exe`.

## Выпуск обновления

1. Поднимите `version` в `package.json`.
2. `npm run dist`
3. Создайте релиз с тегом `vX.Y.Z` и приложите из `dist/` файлы `PS5-Launcher-Setup-X.Y.Z.exe`, `.exe.blockmap` и `latest.yml`:

```bash
gh release create vX.Y.Z dist/PS5-Launcher-Setup-X.Y.Z.exe dist/PS5-Launcher-Setup-X.Y.Z.exe.blockmap dist/latest.yml
```

Установленные лаунчеры увидят новую версию при старте и в настройках.
