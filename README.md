# PS5 Launcher

Лаунчер игр для Windows в стиле интерфейса PS5 — замена Steam Big Picture: полноэкранная оболочка, управление геймпадом, живые фоны, лента с новостями и трофеями, друзья, чат, голосовые звонки и группы.

## Установка

Скачайте **`PS5-Launcher-Installer.exe`** из [Releases](https://github.com/SoFTeR1/ps5-launcher/releases/latest) и запустите — он сам загрузит последнюю версию и установит её. (Классический установщик `PS5-Launcher-Setup-x.y.z.exe` лежит там же — он же используется для автообновлений.)

Дальше лаунчер обновляется сам: **Настройки → Проверить обновления**.

## Управление

| Действие | Геймпад (Xbox / DualSense) | Клавиатура |
|---|---|---|
| Навигация | D-pad / левый стик | Стрелки |
| Выбрать / Играть | A / ✕ | Enter |
| Назад, скрыть заставку запуска | B / ○ | Esc / Backspace |
| Параметры игры, позвонить в чате | Y / △, Start | Q, клавиша меню, правый клик |
| Добавить игру / найти друзей | X / □ | N, Insert |
| Центр управления (меню Home) | Кнопка Xbox (Guide) или View+Start | Home; из любого места — Ctrl+Alt+Home |
| Полный экран вкл/выкл | — | F11 |

**Кнопка Xbox (Guide)** вызывает лаунчер из любого места — даже из игры — и открывает Центр управления: музыка, звук, звонок, друзья, питание, возврат в игру. Повторное нажатие возвращает в игру. Если лаунчер свёрнут или в трее, кнопка просто разворачивает его. Работает с XInput-геймпадами (Xbox и совместимые); если Steam перехватывает кнопку Xbox, используйте View+Start.

Текст с геймпада вводится экранной клавиатурой: ✕/A — клавиша, □/X — стереть, △/Y — пробел, LB — заглавные, Start — готово. Есть раскладки RU, EN, символы и эмодзи.

## Возможности

**Библиотека и запуск**
- Вкладка «Игры»: игры и приложения — exe, ярлыки `.lnk`/`.url`, ссылки `steam://…`; импорт установленных игр Steam с обложками, фонами и логотипами
- Порядок: недавние, по алфавиту или свой (△/Y → «Сделать первой» / «Переставить»)
- Лаунчер — основной слой экрана: игры открываются поверх него, рабочий стол не виден; пока игра запускается, заставка держится поверх всех окон (включая Steam)
- Время в игре и статус «Играет в …» — и для exe, и для игр Steam (время берётся из самого Steam)

**Оформление**
- Свой фон для каждой игры и несколько общих фонов (картинки или видео) со сменой в случайном порядке
- Живые фоны из трейлеров Steam
- Профиль: дата регистрации, последний трофей, недавние игры, друзья и их профили с играми

**Лента** (вниз от кнопки «Играть»): новости игры из Steam, трофеи, «Продолжить», статистика, друзья, музыка, скидки Steam, состояние ПК

**Друзья, чат и голос** (иконка друзей вверху; регистрация не нужна)
- Друзей можно найти по нику или коду; вкладка «Активность» показывает друзей лаунчера и Steam — кто в сети и во что играет
- Чат в стиле Discord: группировка сообщений, эмодзи; сообщения шифруются и доставляются через открытую сеть Nostr, даже если друг был не в сети
- Голосовые звонки напрямую ПК-ПК: громкость собеседника до 200%, «выключить звук», выбор микрофона, шумоподавление
- **Группы** до 5 человек: общий чат и голосовая комната, в которую любой участник заходит сам; друга можно добавить прямо в идущий звонок
- Оверлей поверх всех приложений: виджет звонка как в Discord, входящие звонки и уведомления в стиле Windows 11
- Статус «Играет в …» в Discord — работает сам, если Discord запущен (выключается в настройках)

**Система**
- Микшер громкости приложений в Центре управления
- Питание: сон, перезагрузка, выключение, таймер выключения (30 мин, 1 час, своё время)
- «Свернуть лаунчер» и сворачивание в трей при закрытии окна — чат, звонки и кнопка Xbox продолжают работать
- Раскладка подсказок PlayStation / Xbox / авто, автозапуск с Windows

Для трофеев и друзей Steam нужен бесплатный [Steam Web API-ключ](https://steamcommunity.com/dev/apikey) (Настройки → Аккаунт Steam).

Данные хранятся в `%APPDATA%\PS5 Launcher\library.json`.

## Разработка

```bash
npm install
node node_modules/electron/install.js
npm start
```

Если `node_modules\electron\dist\electron.exe` не появился (бывает на Node 26), распакуйте архив из `%LOCALAPPDATA%\electron\Cache` в `node_modules\electron\dist` и создайте `node_modules\electron\path.txt` с текстом `electron.exe`.

## Выпуск обновления

1. Поднимите `version` в `package.json`.
2. `npm run dist` — соберёт оба установщика.
3. Создайте релиз с тегом `vX.Y.Z` и приложите файлы из `dist/`:

```bash
gh release create vX.Y.Z dist/PS5-Launcher-Setup-X.Y.Z.exe dist/PS5-Launcher-Setup-X.Y.Z.exe.blockmap dist/latest.yml dist/PS5-Launcher-Installer.exe
```

Установленные лаунчеры увидят новую версию при старте и в настройках.
