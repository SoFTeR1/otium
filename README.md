> **Otium** (лат.) — досуг, время для себя.
>
> Интерфейс OTIUM намеренно повторяет оболочку PlayStation 5: так им удобно пользоваться с геймпада с первой минуты, а на большом экране он смотрится как настоящая консоль. Идеально подходит для игры на телевизоре. OTIUM — независимый проект и не связан с Sony Interactive Entertainment; раньше он назывался «PS5 Launcher».

## Установка

Скачайте **`OTIUM-Installer.exe`** из [Releases](https://github.com/SoFTeR1/otium/releases/latest) и запустите — он сам загрузит последнюю версию и установит её. Классический установщик `OTIUM-Setup-x.y.z.exe` лежит там же — он же используется для автообновлений.

Дальше OTIUM обновляется сам: **Настройки → Проверить обновления**. Если у вас стоял PS5 Launcher, он обновится до OTIUM на месте — библиотека, обложки, друзья и настройки переносятся автоматически.

## Управление

| Действие | Геймпад (Xbox / DualSense) | Клавиатура |
|---|---|---|
| Навигация | D-pad / левый стик | Стрелки |
| Выбрать / Играть | A / ✕ | Enter |
| Назад, скрыть заставку запуска | B / ○ | Esc / Backspace |
| Параметры игры, позвонить в чате | Y / △, Start | Q, клавиша меню, правый клик |
| Добавить игру / найти друзей | X / □ | N, Insert |
| Стереть символ в чате и полях ввода | RB (удерживайте — стирает подряд) | Backspace |
| Центр управления (меню Home) | Кнопка Xbox / PS (Guide) или View+Start | Home; из любого места — Ctrl+Alt+Home |
| Полный экран вкл/выкл | — | F11 |

**Кнопка Xbox (Guide)** вызывает OTIUM из любого места — даже из игры — и открывает Центр управления: музыка, звук, звонок, друзья, питание, возврат в игру или её закрытие. Повторное нажатие возвращает в игру. Работает с XInput-геймпадами (Xbox и совместимые); если Steam перехватывает кнопку, используйте View+Start.

Текст с геймпада вводится экранной клавиатурой: ✕/A — клавиша, □/X или RB — стереть, △/Y — пробел, LB — заглавные, Start — готово. Раскладки RU, EN, символы и эмодзи.

## Возможности

**Заставка и атмосфера**
- Заставка при запуске: свечение, огоньки, кольцо OTIUM и синтезированный звук; пропускается любой кнопкой, отключается в настройках
- Свой фон для каждой игры, общие фоны (картинки или видео) со сменой, живые фоны из трейлеров Steam

**Геймпад**
- **Проверка и калибровка** (Настройки → Геймпад): живая схема контроллера — подсвечиваются все кнопки, двигаются стики, заполняются курки. Калибровка измеряет центр и дрожание стиков (мёртвая зона) и их полный ход — меню больше не «уплывает» само
- Подсказки PlayStation / Xbox определяются автоматически

**Библиотека и запуск**
- Игры и приложения — exe, ярлыки `.lnk`/`.url`, ссылки `steam://…`; импорт игр Steam с обложками, фонами и логотипами
- OTIUM — основной слой экрана: игры открываются поверх него, рабочий стол не виден
- «Закрыть игру» прямо из лаунчера — и для Steam, и для добавленных вручную
- Время в игре и статус «Играет в …»

**Лента** (вниз от кнопки «Играть»): новости игры из Steam, трофеи, «Продолжить», статистика, друзья, музыка, скидки Steam, состояние ПК

**Друзья, чат и голос** (регистрация не нужна)
- Поиск друзей по нику или коду; вкладка «Активность» показывает друзей OTIUM и Steam
- Чат в стиле Discord; сообщения шифруются и доставляются через открытую сеть Nostr, даже если друг был не в сети
- Голосовые звонки ПК-ПК, группы до 5 человек с общим чатом и голосовой комнатой
- **Клипы и скриншоты, как Create на PS5.** Пока идёт игра, последние 30 секунд картинки (1080p, 60 кадров) и звука хранятся в памяти: **View + RB** или **Ctrl+Alt+C** сохраняет их в MP4, **L3 + R3** или **Ctrl+Alt+S** делает скриншот. То же есть в центре управления. Меню OTIUM в клип не попадает
- Галерея во вкладке «Медиа»: просмотр со звуком и отправка другу в чат. Файл идёт напрямую между ПК, поэтому оба должны быть в OTIUM; если друг не в сети, он получит файл, когда вы оба окажетесь онлайн (предложение действует 7 дней)
- Настройки: запись клипов (в играх / всегда / выкл) и папка сохранения, которая выбирается на экране геймпадом; по умолчанию `Видео\OTIUM`
- Оверлей поверх игр: виджет звонка, входящие звонки и уведомления

**Система**
- Микшер громкости приложений, сон / перезагрузка / выключение, таймер выключения
- Сворачивание в трей — чат, звонки и кнопка Xbox продолжают работать
- Автозапуск с Windows (заставка тогда без звука)

Для трофеев и друзей Steam нужен бесплатный [Steam Web API-ключ](https://steamcommunity.com/dev/apikey) (Настройки → Аккаунт Steam).

Данные хранятся в `%APPDATA%\OTIUM\library.json`.

## Разработка

```bash
npm install
node node_modules/electron/install.js
npm start
```

Если `node_modules\electron\dist\electron.exe` не появился (бывает на Node 26), распакуйте архив из `%LOCALAPPDATA%\electron\Cache` в `node_modules\electron\dist` и создайте `node_modules\electron\path.txt` с текстом `electron.exe`.

Логотип, иконка, баннер и картинки установщика рисуются кодом: `npm run assets` (`build/make-assets.js`).

## Выпуск обновления

1. Поднимите `version` в `package.json`.
2. `npm run dist` — соберёт оба установщика.
3. Создайте релиз с тегом `vX.Y.Z` и приложите файлы из `dist/`:

```bash
gh release create vX.Y.Z dist/OTIUM-Setup-X.Y.Z.exe dist/OTIUM-Setup-X.Y.Z.exe.blockmap dist/latest.yml dist/OTIUM-Installer.exe
```

Установленные копии увидят новую версию при старте и в настройках.
